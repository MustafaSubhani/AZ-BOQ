# Design references: Quiet Utility

Five screenshots of real business products at 1440 x 900: Plausible Analytics (public demo), Odoo (real ERP demo session) and OpenProject Community. Template-style references (Dreams ERP, Adex) and GitHub repository pages were removed.

What they share: almost no colour, one surface level, rows with hairline separators instead of cards, small type, tight rows, text-led hierarchy.

## 1. Dashboard, light (Plausible)

All KPIs sit in one strip inside a single card: muted label, value, delta. No icons, no boxes. One chart, then plain ranked lists with a faint bar behind each row.

![Dashboard, light](01-plausible-dashboard-light.png)

## 2. Dashboard, dark (Plausible)

Same layout in dark. Surfaces step lighter, borders stay faint, one accent.

![Dashboard, dark](02-plausible-dashboard-dark.png)

## 3. Register list (Odoo, Purchase)

Title, one New button, search, status counts that double as filters, then a plain table. Take the counts-as-filters and the table structure. Leave the pastel count tiles, the filled status pills and the saturated purple button.

![Register list](03-odoo-purchase-register-light.png)

## 4. Dashboard with KPI strip (Odoo, Dashboards)

Four figures with deltas in a row, one chart, a ranked table with inline bars, a list of dashboards on the left. Leave the teal headings and soft blue area fill.

![KPI strip dashboard](04-odoo-dashboard-kpi-strip-light.png)

## 5. Dense table with hierarchy (OpenProject)

Indented parent and child rows, a plain ID column, a coloured text label for type, a small dot plus text for status, avatar and name for the assignee, pagination in the footer. The pattern for BOQ, WBS and work-package registers.

![Dense table](05-openproject-table-light.png)
